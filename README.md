# AWS Certified Solutions Architect – Associate (SAA-C03) Notes

Study notes for the AWS SAA-C03 exam. Each note starts with a **Core idea**, then covers the topic, and ends with a summary, self-check questions and key terms.

Course slides: [Google Drive](https://drive.google.com/file/d/1tQow7KiTYwoz-VEY72hFG8D2MMrWjg4y/view?usp=sharing)

## How to use

1. Read folders `01` → `17` in order — they follow the course.
2. After learning everything, take the [practice tests](https://www.udemy.com/course/aws-certified-solutions-architect-associate-practice-tests-k/) (Udemy).
3. Before the exam, revise with `00_exam_guide`.
